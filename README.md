# Friday - Your Personal AI Assistant

You must create a .env file

```
LIVEKIT_URL=
LIVEKIT_API_KEY=
LIVEKIT_API_SECRET=
GOOGLE_API_KEY=
GEMINI_MODEL=
OLLAMA_URL= "0.0.0.0:11434"
OLLAMA_MODEL=llama3.1:latest
GMAIL_APP_PASSWORD=YOUR_APP_PASSWORD
GMAIL_USER=YOUR_EMAIL_ADDRESS

```
1. Install uv by astral
2. go into mark-orb folder and run ```npm install```
3. run ```uv sync --python 3.12``` in project directory
4. try running python backend file (to download models)
5. run the project by ```npm run dev``` in mark-orb directory
